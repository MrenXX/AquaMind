# AquaMind (WaterSec)

OpenRouter + MiniMax via OpenClaw, Daytona sandbox execution, and WhatsApp gateway helpers.

- **WhatsApp / OpenClaw setup:** see [`openclaw/README-WHATSAPP.md`](openclaw/README-WHATSAPP.md).
- **Apply config patches:** `scripts/apply-openclaw-aquamind-patch.ps1`, `scripts/patch-whatsapp-allowlist.ps1`.
- **Daytona runner (CLI):** `scripts/aquamind_daytona_runner_cli.py`.

Copy `.env.example` to `.env` and fill keys locally (never commit `.env`).
